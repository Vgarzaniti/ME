# Garzaniti IT — Modern Full-Stack & Automation Portfolio

Interactive 3D developer portfolio and freelance services studio for **Valentín Augusto Garzaniti**, built with **React 19**, **Vite**, and modern **CSS 3D / Scroll-Driven Architecture**.

🌐 **Live Demo:** [garzaniti-it.vercel.app](https://me-bd5g3mx34-valentins-projects-52807c55.vercel.app/)

---

## 🚀 Key Features & Architecture

- **Interactive 3D Scroll Showcase (`ScrollShowcase.jsx`)**:
  - Hardware-accelerated CSS 3D perspective (`perspective: 1200px`, `rotateX`).
  - Smooth scroll-driven zoom and 3D hologram cards deconstructing along the Z-axis.
  - Interactive terminal mode (`interactive_terminal.sh`) with live CLI commands (`help`, `services`, `n8n`, `projects`, `stack`, `contact`).
- **Dynamic Freelance Services Studio (`Services.jsx`)**:
  - 4 core offerings: *n8n Workflow Automation*, *Full-Stack Web Apps*, *Custom Management Systems*, and *High-Converting Web Presence*.
  - **Live Architecture Pipeline Simulator**: Real-time event streaming with timestamped logs and reactive JSON payload updates.
- **Direct Project Inquiry & Contact Funnel (`Contact.jsx`)**:
  - On-page project request form with budget tiers and service selectors.
  - Fail-proof multi-channel forwarder (instant WhatsApp dispatch & email client link).
  - Rich social preview cards with authentic GitHub avatar, live repo counters, and direct links.
- **Enhanced Footer & Navigation (`Navbar.jsx`, `Footer.jsx`)**:
  - Glassmorphism navigation with smooth section scrolling.
  - Comprehensive footer with direct email copying, WhatsApp chat, and professional socials.

## 🛠️ Tech Stack

- **Frontend Core:** React 19, JavaScript (ES6+), Vite 7
- **Routing:** React Router DOM 7
- **Testing & Quality:** Vitest, React Testing Library, ESLint 9
- **Deployment:** Vercel Edge Network

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Vgarzaniti/ME.git
cd ME

# Install dependencies
npm install

# Start local development server
npm run dev

# Run test suite
npm run test

# Run linter
npm run lint

# Build for production
npm run build
```
